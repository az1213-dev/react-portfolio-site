## <img src="https://api.iconify.design/lucide:folder-git-2.svg?color=%23006B6A" width="20" height="20" align="center" /> Featured work

**[ClutterCtrl](https://github.com/az1213-dev/clutter-ctrl)** — A fast, zero-dependency terminal file organizer written in pure Python. It sorts cluttered folders by file type, previews every change before touching anything, watches folders in the background, and keeps a per-run log so any run can be undone with a single command.

**[JSON Analyst](https://github.com/az1213-dev/json-analyst)** — A JSON toolkit that runs entirely in your browser. It validates, formats, repairs, compacts, and converts JSON to CSV, and draws the document as an interactive chart or searchable tree. No backend, no telemetry, nothing uploaded anywhere.

## <img src="https://api.iconify.design/lucide:wrench.svg?color=%23006B6A" width="20" height="20" align="center" /> How it's built

React 19 and hand-written CSS — no UI framework, no component library, every layout and animation authored directly.

- **[react-router-dom](https://www.npmjs.com/package/react-router-dom)** — client-side routing across the home page and legal pages
- **[react-scroll](https://www.npmjs.com/package/react-scroll)** — smooth in-page section navigation
- **[Formspree](https://formspree.io)** — contact form delivery
- **[Vercel](https://vercel.com)** — hosting and privacy-friendly analytics
- **[Jest & React Testing Library](https://testing-library.com/)** — unit tests, run against every push by **[GitHub Actions](https://github.com/features/actions)**

## <img src="https://api.iconify.design/lucide:sparkles.svg?color=%23006B6A" width="20" height="20" align="center" /> Details worth noticing

- **Responsive on any screen** — layouts reflow across phone, tablet, and desktop breakpoints rather than only the common ones
- **Motion with manners** — hover states, lifts, and scroll animations throughout, all of which stand down for visitors who set `prefers-reduced-motion`
- **Vector-first assets** — the brand mark and project logos are hand-authored SVG, so they stay sharp on any display
- **Accessible by default** — semantic landmarks, labelled controls, live-region status messages, and visible keyboard focus rings
